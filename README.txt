Три Цены Finance RU — PWA launcher

TARGET: https://3ceni-finance-platform.streamlit.app

Как разместить на GitHub Pages:
1. Скопировать содержимое этой папки в отдельную папку репозитория, например mobile/.
2. В GitHub Settings -> Pages выбрать источник публикации (ветка main, нужная папка/корень согласно вашей схеме).
3. Открыть опубликованный HTTPS-адрес в Safari на iPhone.
4. Поделиться -> На экран Домой.

На мобильном браузере страница показывает установку. После запуска с домашнего экрана переходит в Streamlit.
На десктопе переход в Streamlit выполняется автоматически.
